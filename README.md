# Syross P. Algabre | Portfolio

Personal portfolio of Syross P. Algabre, a web developer based in Davao City, Philippines, with more than ten years of experience in Vue, React, TypeScript and Laravel.

**Live site:** [https://YOUR-PROJECT.vercel.app](https://YOUR-PROJECT.vercel.app)

## Features

- Single-page layout with About, Experience, Skills, Education and Contact sections
- Dark and light mode that remembers the visitor's choice
- Hero mockup with a Design/Code toggle
- Responsive on phones, tablets and desktops
- Contact form that opens the visitor's email app
- Inline SVG graphics, so there are no image files to maintain

## Tech stack

- HTML
- JavaScript (vanilla)
- [Tailwind CSS](https://tailwindcss.com/) via CDN
- Google Fonts: Bricolage Grotesque, DM Sans and JetBrains Mono

## Run locally

No build step is needed. Open `index.html` in your browser, or serve the folder:

```bash
npx serve .
```

## Edit the content

Open `index.html` and find the `<script>` block near the bottom:

- `jobs` holds the work experience entries
- `skills` holds the skill groups and tags

Contact details are in the Contact section of the same file.

## Deploy to Vercel

1. Push this repository to GitHub.
2. Go to [vercel.com/new](https://vercel.com/new) and import the repository.
3. Set **Framework Preset** to **Other**. Leave the build command and output directory empty.
4. Click **Deploy**.

Every push to the main branch redeploys the site automatically.
